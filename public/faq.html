Frequently Asked Questions

Everything you need to know about setting up, running, and customizing JARVIS for your workflow.

Is JARVIS completely free to use?

Yes, the core JARVIS software is 100% free and open-source under the GNU General Public License v3.0 (GPLv3). The system can run entirely on local Ollama or LM Studio models for zero API cost. If you use cloud APIs like Groq, Gemma, or Regolo, you may incur standard API usage costs depending on their respective free tiers.

Can I run it completely offline?

Absolutely. You can point JARVIS to any local OpenAI-compatible endpoint. By running Ollama or LM Studio locally and updating the CUSTOM_BASE_URL in your .env, you can achieve 100% local, offline inference.

What hardware do I need to run JARVIS?

Very little. JARVIS was developed and tested on an Intel i5-3210M (2012) with 4 GB RAM. Because JARVIS uses cloud LLM providers by default, you don't need a powerful GPU or 32 GB of RAM. If your machine can run Windows 11 and a browser, it can run JARVIS. More RAM = faster embedding loads.

What is Live Mid-Execution Correction?

The AgenticBrain loop is interruptible. If you change your mind mid-task — for example, saying "not WhatsApp, send an email instead" — Jarvis absorbs the correction, revises its plan in-place, and keeps already-completed steps intact. No full restart, no hallucinated apology loop. This runs only in AgenticBrain mode; FastBrain is stateless.

What is the Contributor License Agreement (CLA)?

JARVIS uses a CLA to ensure the project can remain open-source while allowing commercial licensing for enterprises. By submitting a Pull Request, you agree to transfer copyright of your contribution to Kaif Ansari, enabling the project to be distributed under both GPLv3 and proprietary licenses without seeking further permission.

Does it work on Mac and Linux?

Currently, JARVIS is Windows-only (Windows 10/11). The GUI automation, PC monitor, and mobile bridge assume Windows paths and APIs (pywin32, comtypes, Windows Registry). Linux and macOS are not currently planned, but community contributions are welcome if you'd like to port it.

How does Mobile Control work?

Mobile control uses Termux SSH over a Tailscale tunnel — no ADB, no USB cable. Install Termux + Termux:API from F-Droid, configure OpenSSH (sshd) with key-based authentication, connect both devices via Tailscale, and add your device ID to the connected devices file. Jarvis can then control flashlight, vibrate, battery, camera, notifications, and open apps via termux-* API commands.

Will it accidentally delete my files?

JARVIS employs a strict shlex tokenization and path canonicalization layer that auto-blocks highly destructive commands (like rm -rf /). Additionally, our Human-in-the-Loop (HITL) system ensures it asks for consent before major actions.

Why are WhatsApp and Telegram separated?

WhatsApp uses the Baileys Node.js web socket bridge for stable connections, requiring a QR code scan. Telegram uses the native MTProto API via Telethon for deeper OS integration and remote bot control. Both are managed safely as background services by the ServiceWatchdog.
