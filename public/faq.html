payments Is JARVIS completely free to use? expand_more

Yes, the core JARVIS software is 100% free and open-source under the GNU General Public License v3.0 (GPLv3).

The system can run entirely on local Ollama or LM Studio models for zero API cost. If you use cloud APIs like Groq, Gemini, or Regolo, you may incur standard API usage costs depending on their respective free tiers.

wifi_off Can I run it completely offline? expand_more

Absolutely. You can point JARVIS to any local OpenAI-compatible endpoint. By running Ollama or LM Studio locally and updating PRIMARY_BASE_URL and FALLBACK_BASE_URL in your .env, you achieve 100% local, offline inference.

The local embedding model (BAAI/bge-small-en-v1.5) and RapidOCR already run on-device — no cloud calls there either.

developer_board What hardware do I need to run JARVIS? expand_more

Very little. JARVIS was developed and tested on an Intel i5-3210M (2012) with 4 GB RAM.

Because JARVIS uses cloud LLM providers by default, you don't need a powerful GPU or 32 GB of RAM. If your machine can run Windows 11 and a browser, it can run JARVIS. More RAM = faster embedding loads and snappier boot.

sync What is Live Mid-Execution Correction? expand_more

The AgenticBrain loop is interruptible. If you change your mind mid-task — for example, saying "not WhatsApp, send an email instead" — JARVIS absorbs the correction, revises its plan in-place, and keeps already-completed steps intact.

No full restart, no hallucinated apology loop, no lost progress. This runs only in AgenticBrain mode — FastBrain is stateless and doesn't support mid-run re-planning.

handshake What is the Contributor License Agreement (CLA)? expand_more

JARVIS uses a CLA to ensure the project can remain open-source while allowing commercial licensing for enterprises.

By submitting a Pull Request, you agree to grant the maintainer (Kaif Ansari) the right to use your contribution under both GPLv3 and any future commercial licenses. This keeps the project legally clean and fully funded.

devices Does it work on Mac and Linux? expand_more

Currently, JARVIS is Windows-only (Windows 10/11). The GUI automation, PC monitor, and mobile bridge assume Windows paths and APIs (pywin32, comtypes, Windows Registry).

Linux and macOS are not currently planned, but community contributions are welcome if you'd like to port it.

phone_android How does Android control work? expand_more

Mobile control uses a persistent WebSocket bridge over local WiFi — no ADB, no USB cable, no cloud relay.

Install Termux + Termux:API from F-Droid, open the bridge dashboard at 127.0.0.1:8090, scan the QR code, and you're connected. JARVIS can then control flashlight, vibrate, battery, camera, notifications, and open apps via termux-* API commands.

verified_user Will it accidentally delete my files? expand_more

JARVIS employs strict shlex tokenization and path canonicalization that auto-blocks destructive commands like rm -rf / or del /f /s /q on system paths.

Additionally, the Human-in-the-Loop (HITL) system ensures it asks for consent before any major action. You see the exact operation, approve or reject, and nothing happens without your explicit confirmation.

chat Why are WhatsApp and Telegram separate systems? expand_more

WhatsApp uses the Baileys Node.js WebSocket bridge for stable connections, requiring a QR code scan once. Telegram uses the native MTProto API via Telethon for deeper OS integration and remote bot control.

Both are managed safely as background services by the ServiceWatchdog, which auto-restarts them if they crash.

extension How does MCP integration work? expand_more

MCP (Model Context Protocol) lets JARVIS connect to 18,000+ community-built tool servers — GitHub, Brave Search, SQLite, Notion, Slack, Docker, and more — via a single JSON entry in Data/mcp_servers.json.

Tools are auto-discovered at startup and namespaced as mcp__<server>__<tool>. Zero core code changes needed to add new capabilities.

shield Is my data safe? expand_more

Yes. Credentials are AES-encrypted locally. Conversation history and memory graphs stay on disk. There's zero telemetry and no analytics — you can audit the entire codebase on GitHub.

Only LLM API calls leave your machine, and you can switch to local models entirely to eliminate even that. See the full Privacy Policy.

download How long does installation take? expand_more

On a warm connection, the full install takes about 5–10 minutes: clone, install Python deps, install Node deps for the WhatsApp bridge, register the CLI.

Follow the Quick Start guide for a copy-paste walkthrough.
