Introduction

JARVIS is an open-source autonomous AI operating system for Windows. It reads codebases, sends emails, controls your Android phone, remembers you across months, and re-plans mid-task when you interrupt. This documentation covers everything from installation to advanced configuration.

Live Correction

Lifelong Memory

Five-tier memory with weighted graph + hybrid RAG.

MCP Native

18,000+ community servers via a single JSON entry.

Dual-Engine Voice

Azure on-device + Vosk fallback, zero cloud round-trip.

4GB RAM

Verified on a 2012 Intel i5-3210M laptop.

phone_android

Android Control

WebSocket bridge — calls, SMS, GPS, torch, clipboard.

Who is this for?link

JARVIS is built for developers and power users who want an AI that actually does things — not just chats. If you want to:

  • Automate real work across your PC, phone, and communications
  • Run an AI agent on modest hardware (no GPU required)
  • Extend capabilities without touching code (via MCP)
  • Keep all memory and data on your own disk
  • Use any OpenAI-compatible LLM, including local models

Then this is for you. If you need a polished IDE copilot, use Claude Code or Cursor.

info

Windows-only. JARVIS relies on Windows APIs for GUI automation, PC monitoring, and the Termux bridge. Mac/Linux support is on the roadmap.

Installation

Detailed walkthrough for a clean install. Skip this if you completed Quick Start successfully.

1. Clone the repositorylink

terminalpowershell 
git clone https://github.com/thekaifansari01/Jarvis-OS-Agent.git
cd Jarvis-OS-Agent

2. Create virtual environmentlink

JARVIS installs ~40 Python packages. Always use a virtual environment to avoid conflicts with your global Python.

terminalpowershell 
python -m venv .venv
.\.venv\Scripts\Activate.ps1
warning

If PowerShell blocks the activation script, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned in an elevated terminal.

3. Install Python packageslink

terminalpowershell 
pip install --upgrade pip
pip install -r requirements.txt
pip install mcp

This installs the core runtime plus optional dependencies like Flask (RAG dashboard), psutil (PC monitoring), and Pillow (vision).

4. Install WhatsApp bridgelink

The WhatsApp integration is powered by a Node.js server using Baileys. Skip this step if you don't need WhatsApp.

terminalpowershell 
cd tools/Messanger/whatsapp/BaileysServer
npm install
cd ../../../..

5. Register global CLIlink

This makes the jarvis command available system-wide. Run it from the repo root with the virtual environment active:

terminalpowershell 
python SetupRegistry.py

Open a new terminal to verify installation:

terminalpowershell 
jarvis --help

6. Enable MCP (optional)link

To add external tools via the Model Context Protocol, create Data/mcp_servers.json. See the MCP section for full details.

Environment Configuration

All API keys and configuration live in a single .env file at the repo root. Copy .env.example to .env and fill in the values you need.

PRIMARY_MODELModel name, e.g. llama-3.3-70b-versatile

Optional variableslink

The following are only needed for the integrations you actually use:

  • Voice: AZURE_SPEECH_KEY, AZURE_SPEECH_REGION, AZURE_KEYWORD_MODEL_PATH
  • Telegram: TELEGRAM_API_ID, TELEGRAM_API_HASH
  • Image generation: IMAGE_GEN_API_KEY, IMAGE_GEN_ENDPOINT
  • TTS: TTS_API_KEY (falls back to Edge TTS if absent)

Using local LLMslink

For 100% local execution, point both providers at your local OpenAI-compatible server:

description.env (Ollama example) 
PRIMARY_API_KEY=ollama
PRIMARY_BASE_URL=http://localhost:11434/v1
PRIMARY_MODEL=llama3.1

FALLBACK_API_KEY=ollama
FALLBACK_BASE_URL=http://localhost:11434/v1
FALLBACK_MODEL=llama3.1
info

Both PRIMARY_BASE_URL and FALLBACK_BASE_URL must end with /v1. This is the standard OpenAI-compatible route.

Voice Setup

JARVIS ships with dual-engine wake word detection, premium STT, and low-latency TTS. Everything runs on-device by default — no cloud round-trip for wake word.

Wake word engineslink

Two independent engines, auto-selected on boot:

EngineWhen activeAccuracy
Azure Custom Keyword If Data/model/azure/jarvis.table exists 97%+
Vosk KWS Fallback if Azure unavailable ~66%

Building an Azure wake modellink

This is a one-time 30-minute process. After training, no API key or network call is needed for wake word.

  1. Create a Foundry resource Go to Azure Portal → Foundry → Speech. Copy your key and region.
  2. Train a Custom Keyword Open Speech Studio → Custom Keyword → Create project (English US).
  3. Choose your model Basic (~30 min queue) or Advanced (~48h for better accuracy).
  4. Download the .table file Extract the .table from the zip and save as Data/model/azure/jarvis.table.
  5. Restart JARVIS Azure engine activates automatically. Check startup logs for confirmation.
info

No Azure subscription? Vosk works out of the box. It auto-downloads a small model on first run — no config required.

Speech-to-textlink

STT uses Deepgram Nova-2 with a self-healing LTM vocabulary cache. Entity names from your memory graph are auto-synced into Deepgram's vocabulary, so it correctly recognizes names, projects, and jargon over time.

check_circle

Zero training needed. Add someone to your memory and Deepgram starts recognizing their name within a session.

Text-to-speechlink

Default TTS uses Sarvam for English + Hinglish (low-latency). Falls back to Edge TTS if the API key is missing. First audio typically lands in 0.8–2 seconds.

Memory & RAG

JARVIS has five tiers of memory — from verbatim message history to long-term semantic graphs and hybrid RAG over your documents.

The five tierslink

#TierWhat it storesRetention
1EpisodicRaw messages + execution logs15 days (2 raw + 13 summarized)
2SemanticWeighted property graph (facts, people, contacts)Lifetime, with decay
3RAGIndexed documents via hybrid BM25 + vectorUntil deleted
4Ephemeral10-min TTL artifacts (last screenshot, generated image)Auto-purged
5BehavioralPatterns extracted from your habits & routinesLifetime, with decay

RAG Indexer Dashboardlink

JARVIS ships with a web dashboard for managing indexed folders and filters. Open it after launching:

languagebrowser 
http://127.0.0.1:8080

On first boot, the indexer auto-adds your Documents folder. You can add more from the Folders tab — paste any absolute path and click Add & Index.

Adding a new folderlink

  1. Open the dashboard at 127.0.0.1:8080.
  2. Go to Folders tab.
  3. Paste an absolute path, e.g. D:/Projects or C:\Users\You\Desktop\notes.
  4. Click Add & Index. Progress streams live.
warning

System paths are auto-blocked. Paths like C:\Windows, Program Files, and dev garbage (node_modules, .git, venv) are skipped automatically. Sensitive paths like .ssh and .aws trigger warnings.

Filters & exclusionslink

Open the Filters tab to tune indexing:

  • Max file size — default 5 MB. Larger files are skipped.
  • Max depth — how deep to recurse.
  • Custom ignore patterns — e.g. *.log, backup_*, node_modules.

Rebuilding the indexlink

If embeddings feel stale or you changed the model:

terminalpowershell 
# Purge the vector index
Remove-Item -Recurse -Force Data\jarvis_memory\rag_chroma_db
Remove-Item Data\jarvis_memory\rag_hashes.json

# Restart JARVIS to rebuild automatically
jarvis

MCP Integration

The Model Context Protocol lets JARVIS plug into 18,000+ community-built tool servers — GitHub, Brave Search, SQLite, Postgres, Notion, Slack, Docker, Puppeteer, and more — via a single JSON file.

How it workslink

When Data/mcp_servers.json exists with valid configs, JARVIS:

  • Spawns each configured MCP server as a subprocess
  • Performs a JSON-RPC handshake to discover tools
  • Converts tool schemas into native function declarations
  • Exposes them to the agent as mcp__<server>__<tool>

Configuration examplelink

Create Data/mcp_servers.json:

descriptionmcp_servers.json 
{
  "mcpServers": {
    "github": {
      "command": "cmd",
      "args": ["/c", "npx", "-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxxxxxxxxxxx"
      },
      "call_timeout": 60
    },
    "sqlite": {
      "command": "cmd",
      "args": ["/c", "npx", "-y", "@modelcontextprotocol/server-sqlite", "C:/data/mydb.sqlite"]
    }
  }
}

Save the file, restart JARVIS once, and check the startup log:

terminalstartup log 
MCP: server 'github' connected (40 tools).
MCP: server 'sqlite' connected (6 tools).
MCP: ready with 46 tools from 2 servers.

Windows notelink

warning

On Windows, npx is a .cmd shim that breaks stdio pipe propagation when spawned directly. Always wrap Node-based servers with "command": "cmd", "args": ["/c", "npx", "-y", "..."].

Popular serverslink

ServerWhat it addsAPI key?
GitHubRepos, issues, PRs, searchPersonal access token
Brave SearchWeb, news, local searchFree tier (2k/mo)
SQLiteNatural-language DB queriesNone
PostgresDB queries on live databasesConnection string
NotionPages, databases, commentsIntegration token

info

Skip redundant servers. Filesystem MCP overlaps with native file_operations. Memory MCP overlaps with the built-in 5-tier memory. Puppeteer overlaps with gui_controller. Only add servers that introduce net-new capabilities.

Disabling MCPlink

MCP is opt-in by design. Delete Data/mcp_servers.json or set it to { "mcpServers": {} }. JARVIS boots identically to the pre-MCP version with zero overhead.

Android Bridge

Control your Android phone natively from Windows using Termux and a WebSocket bridge. No SSH required, no cloud relay.

Setuplink

  1. Install Termux and Termux:API on your phone via F-Droid (not Google Play — that version is outdated).
  2. Connect both devices to the same WiFi. The bridge runs over local network only.
  3. Open the bridge dashboard on your PC: http://127.0.0.1:8090.
  4. Scan the QR code with your phone, or copy the setup command into Termux.
  5. Approve Termux:API prompts as they appear — SMS, contacts, storage, location.

What you can dolink

CategoryExamples
FilesDrag & drop files, receive via Android Share menu
TelecomMake calls, read/send SMS, ring phone
SensorsGPS location, battery level, storage, torch
ClipboardSync clipboard both ways
PhotosFetch latest photo, screenshot

Persistent background modelink

The bridge runs a wake-lock that keeps it alive even when your phone is locked. It survives app switches and network changes.

security

LAN-only. The bridge binds to 127.0.0.1:8090. It is never exposed to the internet. If you need remote control, use the Telegram bot instead.

Telegram Bot

Trigger silent background PC commands from anywhere via Telegram. Perfect for when you're away from your desk.

Setuplink

  1. Create a bot — message @BotFather on Telegram, send /newbot, follow the prompts, and copy the token.
  2. Stop JARVIS on your PC. The bot activation command requires it to be offline.
  3. Run activation: jarvis bot --activate
  4. Paste your BotFather token when prompted.
  5. Start JARVIS again. Send any message to your bot on Telegram to confirm.

Remote commandslink

Once connected, you can message your bot on Telegram the same way you'd talk to JARVIS at your desk. Examples:

  • "Open VS Code"
  • "What's my CPU usage?"
  • "Summarize my last 3 emails"
  • "Take a screenshot and send it"
  • "Lock the PC"

Commands run silently in the background — your active desktop session is untouched.

Status & controllink

terminalpowershell

jarvis bot --deactivate  # revoke & offline the bot

Architecture

JARVIS is resilient by design. Every layer has a fallback; every provider has a failover; every tool has a watchdog.

Dual-brain routinglink

A semantic router picks the right brain for each command:

BrainWhenLatency
FastBrainShort commands, OS toggles, casual chat<2s
AgenticBrainComplex engineering, comms, memory, visionMulti-step

3-tier fallback chainlink

  1. Tier 1 — Semantic Router Cloud-based; classifies intent via a fast LLM.
  2. Tier 2 — FastBrain If the router API times out, FastBrain handles routing.
  3. Tier 3 — Local rule-based If both fail, keyword + heuristic rules take over.

Provider failoverlink

Every LLM call tries PrimaryProvider first. On failure (timeout, rate limit, 5xx), it retries FallbackProvider — a completely separate OpenAI-compatible endpoint. Configure both in .env.

ServiceWatchdoglink

Monitors and auto-restarts:

  • STT Popup, Baileys WhatsApp server
  • Mobile Bridge (:8090), Telegram bot
  • Indexer Dashboard (:8080), MCP Manager

Crashes trigger a cooldown backoff. Unauthenticated services are skipped, not restarted endlessly.

Troubleshooting

Common issues and their fixes. For anything not listed here, open an issue on GitHub.

ModuleNotFoundError on startuplink

Your virtual environment isn't active, or dependencies are missing:

terminalpowershell 
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Wake word not workinglink

JARVIS requires at least one wake-word model:

  • Azure: Data/model/azure/jarvis.table
  • Vosk: Data/model/vosk-model-small/ (auto-downloads on first run)

If both are missing, JARVIS boots with voice disabled — no crash, just text mode via Ctrl+Shift+J.

WhatsApp won't startlink

  1. Verify Node.js 18+ — run node --version.
  2. Reinstall the bridge — cd tools/Messanger/whatsapp/BaileysServer && npm install.
  3. Check port 3000 — if busy, kill the process or change the port.

MCP tools not appearinglink

  1. Confirm pip install mcp succeeded.
  2. Verify Data/mcp_servers.json exists and is valid JSON. Check with:
    terminalpowershell 
    python -c "import json; json.load(open('Data/mcp_servers.json'))"
  3. Check startup logs for MCP: ready with N tools.

MCP server logs "Connection closed"link

npx is a .cmd shim on Windows. Wrap with cmd /c:

descriptionjson 
{
  "command": "cmd",
  "args": ["/c", "npx", "-y", "@modelcontextprotocol/server-github"]
}

RAG indexer stucklink

If indexing hangs on a folder, check startup logs for permission_denied=N. Windows legacy junctions (My Music, My Pictures) are auto-skipped. Reduce scope via the dashboard filters.

Primary provider keeps failinglink

  • Verify PRIMARY_BASE_URL ends with /v1.
  • Check PRIMARY_API_KEY is valid (not expired).
  • Confirm model name exists at that provider.
  • JARVIS auto-falls back to FALLBACK_* if primary fails — check logs for confirmation.

Live correction is ignoredlink

Live correction only works in AgenticBrain mode. FastBrain is stateless and doesn't support mid-run re-planning. Check the router decision at the top of any log — you'll see Decision -> AGENTIC when the agentic loop is active.

Dashboard won't openlink

Confirm Flask is installed:

terminalpowershell 
pip install flask

If port 8080 is busy, JARVIS auto-shifts to 8081–8095. Check startup logs for the actual port.

Frequently Asked Questions

Short answers to the most common questions.

Is it really free?add
Yes. GPLv3. You can run it entirely on local LLMs with zero API cost, or mix free-tier cloud providers. No subscription, no feature gate, no telemetry.
Does it work on Mac or Linux?add
Currently Windows-only. GUI automation, PC monitoring, and the Termux bridge assume Windows paths and APIs. Cross-platform support is on the roadmap.
Is my data safe?add
Credentials are AES-encrypted locally. Conversation history and memory graphs stay on disk. Only LLM API calls leave your machine — and you can switch to local models entirely with zero cloud calls.
What hardware do I need?add
JARVIS was developed on an Intel i5-3210M with 4 GB RAM. If your machine can run Windows 11 and a browser, it can run JARVIS. More RAM = snappier local embeddings and faster boot.
Does RAG / memory need API keys?add
No. Both the LTM semantic graph and RAG index use the local BAAI/bge-small-en-v1.5 model (33M params, ~130 MB). Embeddings run on CPU with zero cloud calls, quotas, or cost.
Which LLMs does it support?add
Any OpenAI-compatible endpoint. Groq, Regolo, OpenRouter, Gemini's OpenAI endpoint, Ollama, LM Studio, vLLM, or any OpenAI-schema API. Configure two providers — PRIMARY_* and FALLBACK_* — and JARVIS auto-routes on failure.
Can I add capabilities without editing code?add
Yes — via MCP. Add a JSON entry to Data/mcp_servers.json, restart once, and the server's tools appear in the Agentic Brain automatically as mcp__<server>__<tool>.
How is this different from ChatGPT or Claude?add
Those are chat interfaces. JARVIS is an agent — it takes actions on your actual system, remembers you across months, corrects itself mid-task, and reaches out proactively. It doesn't just answer; it does.
