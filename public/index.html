How it works

Wake. Route. Act.

Three steps. Zero configuration. Every layer has a fallback so nothing blocks you.

01

Wake

Say "Jarvis" — the on-device Azure Custom Keyword model picks it up in under 200ms with 97%+ accuracy. Or hit Ctrl+Shift+J to type. No cloud round-trip either way.

02

Route

A semantic router decides per command: FastBrain for simple chat (<2s), AgenticBrain for multi-step work. Three tiers of fallback if the router itself fails.

03

Act

Real tools, real effects. Files written, emails sent, calendars updated. Interrupt mid-run — the loop re-plans per step. Nothing single-point-of-failure.

Get running

Up and running in one command.

Windows 10/11. Sit back, relax, and let the automated installer set everything up for you.

terminal PowerShell (1-Click Installer)
# Paste this in PowerShell and press Enter
Set-ExecutionPolicy Bypass -Scope Process -Force; [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; & ([scriptblock]::Create((Invoke-RestMethod -Uri 'https://raw.githubusercontent.com/thekaifansari01/Jarvis-OS-Agent/main/install.ps1')))
01 / CONFIG

API keys prompt

The installer creates .env automatically and interactively prompts for API keys. Works with Groq, Regolo, OpenRouter, Ollama, LM Studio, or any OpenAI-compatible endpoint.

02 / OPTIONAL

Enable MCP

Run jarvis mcp add to hot-load 18,000+ tools live — GitHub, Brave, SQLite, Notion, Docker — with zero restarts.

03 / READY

Say "Jarvis"

Questions

Frequently asked.

Is it really free?add
Yes. GPLv3. You can run it entirely on local LLMs with zero API cost, or mix free-tier cloud providers. No subscription, no feature gate, no telemetry.
Does it work on Mac or Linux?add
Currently Windows-only. GUI automation, PC monitor, and the Termux bridge assume Windows paths and APIs. Cross-platform support is on the roadmap.
Is my data safe?add
Credentials are AES-encrypted locally. Conversation history and memory graphs stay on disk. Only LLM API calls leave your machine — and you can switch to local models entirely with zero cloud calls.
What hardware do I need?add
JARVIS was developed on an Intel i5-3210M with 4 GB RAM. If your machine can run Windows 11 and a browser, it can run JARVIS. More RAM = snappier local embeddings and faster boot.
Does RAG / memory need API keys?add
No. Both the LTM semantic graph and RAG index use the local BAAI/bge-small-en-v1.5 model (33M params, ~130 MB). Embeddings run on CPU with zero cloud calls, quotas, or cost. Only LLM/voice/comms need keys.
Which LLMs does it support?add
Any OpenAI-compatible endpoint. Configure two providers — PRIMARY_* and FALLBACK_* — and JARVIS auto-routes on failure. Works with Groq, Regolo, OpenRouter, Gemini's OpenAI endpoint, Ollama, LM Studio, vLLM, or any OpenAI-schema API.
Can I add capabilities without editing code?add
Yes — via MCP. Run jarvis mcp add <name> <command> (or save Data/mcp_servers.json), and JARVIS hot-reloads the server live within 2 seconds without restarting. Tools appear automatically as mcp__<server>__<tool>.
How is this different from ChatGPT or Claude?add
Those are chat interfaces. JARVIS is an agent — it takes actions on your actual system, remembers you across months, corrects itself mid-task, and reaches out proactively. It doesn't just answer; it does.
How do I uninstall JARVIS?add
A single PowerShell command. It stops all background services, cleans the registry, removes PATH entries, and deletes the install folder. The uninstaller first prompts to back up your .env, Lifelong Memory Graph, and MCP config to the Desktop (default Yes). See the Uninstall guide for full details.
