Every feature built to solve real problems — not just hype.

Line-Drift-Free Code Editing

Exact replace_block diffs instead of fragile line numbers — eliminates the classic "line-drift bug". Automatically catches syntax errors via AST linter and self-corrects.

Proactive HITL

Background listeners for Gmail, WhatsApp, Telegram, and Calendar detect events and ask for permission before modifying critical data.

Mobile Phone Control

Control your Android via ADB over Tailscale — lock/unlock, open apps, make calls, read SMS, toggle WiFi/Data, and adjust volume straight from your PC.

Multi-LLM Failover

Seamlessly switches between Regolo, Gemini, OpenRouter, or local models (Ollama, LM Studio) if primary hits rate limits to ensure zero downtime.

Telegram Remote Bot

Control your Windows PC from anywhere globally. Send commands to your remote bot and Jarvis executes them silently in the background.

Bidirectional Property Graph & Hybrid RAG

Built on NetworkX. Extracts entities into an enterprise-grade Property Graph with bidirectional edge routing, temporal decay, and metadata context indexing. Merged with a Hybrid RAG system (BM25 + Vector + RRF) for unparalleled zero-latency semantic recall.
